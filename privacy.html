Privacy Policy

Last updated 22 August 2026

This policy covers the private Pinterest API application used by the operator of the Pinterest account @40andLosingIt to publish her own content to her own boards.

Who this application is for

This is a single-operator tool. It is not offered to the public, it has no other users, and it does not create accounts for anyone. It exists so the account owner can schedule and publish her own Pins without doing each one by hand.

What it accesses

  • The account owner's own Pinterest boards, in order to publish Pins to them.
  • The account owner's own Pin and board analytics, in order to report on how her own content performed.
  • Images the account owner created herself, hosted publicly at this same domain.

What it does not do

  • It does not access, collect, store, or process any other Pinterest user's personal data.
  • It does not read other users' private boards, messages, or profile information.
  • It does not sell, share, transfer, or disclose data to any third party.
  • It does not use Pinterest data for advertising, profiling, or training any model.
  • It does not place cookies or run analytics on this page.

Storage and retention

Access tokens are stored locally on the account owner's own computer and are never published, shared, or committed to this repository. Analytics figures retrieved from Pinterest are kept in private local files belonging to the account owner. No data is stored on any external server.

Deletion

The account owner can revoke this application's access at any time from Pinterest's own account settings, which immediately ends all access. Locally stored tokens and figures can be deleted by deleting the local files.

Changes

If this policy changes, the updated version will be posted on this page with a new date above.

Contact

Questions about this policy can be sent to the address listed on the Pinterest developer application for @40andLosingIt.

This page exists to satisfy Pinterest's developer platform requirement that every application publish a privacy policy at a public URL.
